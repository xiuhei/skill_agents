# 临时工作区规范

当前目录是临时任务工作区（tmp），请严格遵守以下规则：

- **禁止无关检索**：当前目录及其子目录中已有的文件均与当前任务无关。除本次任务明确要求外，无需主动检索、读取、分析或复用其他任务的文件。

- **禁止污染根目录**：不得在当前目录直接创建、下载、生成或解压任何任务文件，包括代码、文档、脚本、图片、日志、缓存及临时文件。
- **一任务一目录**：每个独立任务必须在当前目录下创建一个专属子目录，任务产生的所有文件必须放在该目录内，不同任务不得混用目录。
- **先建目录，再执行任务**：开始任务时，首先创建任务目录，后续所有文件操作、命令执行及工具输出均以该目录为工作位置。注意修改工具默认输出路径，避免文件落入根目录。
- **合理组织文件**：根据任务需要创建 `src`、`output`、`assets`、`scripts`、`logs` 等子目录，避免文件无序堆积。
- **完成后检查**：任务结束前检查当前根目录，将本次任务误生成在根目录的文件移动到对应任务目录，并清理不必要的临时文件。不得修改或删除原有文件。

**核心原则：当前目录只负责存放各任务文件夹，绝不直接存放任何任务产物。**
